# Repository files

These are the project files I have found and recovered from the Boeing 787 cockpit build.

## Wiring and architecture
- `wiring/787-full-cockpit.vsdx` — overall cockpit wiring/design file
- `wiring/MCP-architecture-v4.vsdx` — later MCP wiring architecture
- `wiring/EFIS-pilot.vsdx` and `wiring/EFIS-copilot.vsdx` — EFIS wiring diagrams
- `wiring/MFK.vsdx` — MFK panel wiring
- `wiring/displays.vsdx` — display wiring work

## Control mappings
- `mappings/EFIS-mappings.docx` — EFIS pin/control mappings
- `mappings/MFK-mappings.docx` — MFK pin/control mappings
- `mappings/MCP-mappings-v3.docx` — MCP mappings
- `mappings/MCP-mappings-v2.xlsx` — spreadsheet version of MCP mappings

## MobiFlight
- `mobiflight/787.mcc` — surviving MobiFlight configuration with simulator input/output mappings

## Component planning
- `components/display-pin-tables.docx` — display pin tables
- `components/display-specifications.docx` — specifications I used while planning the cockpit displays

## Visio stencils
- `stencils/` — reusable breakout, circuit, and Arduino Mega shapes used while drawing the wiring diagrams

## Photos
- `photos/` — photos documenting various panels, prototypes, wiring, and the build process.
